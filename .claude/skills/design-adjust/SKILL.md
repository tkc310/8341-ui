# 既存デザインシステム調整

`design-principles` スキルの「モード 2: 既存の調整」を直接呼ぶ入口。

1. `../design-principles/SKILL.md` を読み、「ルールの優先順位」と手順 1（前提条件のヒアリング。既存の DESIGN.md から分かることは聞かない）を行う
2. `../design-principles/mode-2-adjust.md` を読み、調整する領域に関係する `references/` だけを読む
3. トークンやコンポーネントを追加・変更し、DESIGN.md を更新する（成果物は mode-2-adjust.md）

ルールのギャップに気づいたら `../design-principles/feedback.md` の手順でユーザーに伝える。
