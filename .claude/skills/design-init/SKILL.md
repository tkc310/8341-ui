# 新規デザインシステム作成

`design-principles` スキルの「モード 1: 新規作成」を直接呼ぶ入口。

1. `../design-principles/SKILL.md` を読み、「ルールの優先順位」と手順 1（前提条件のヒアリング）を行う
2. `../design-principles/mode-1-init.md` を読み、その「読む順序」で必要な `references/` だけを読む
3. UI の方向性 → 特化ルール → 原則 → WCAG の順でルールを適用し、DESIGN.md を作る（成果物は mode-1-init.md）

ルールのギャップに気づいたら `../design-principles/feedback.md` の手順でユーザーに伝える。
