# ルールへのフィードバック

対話中にルールの改善点が見つかったときに読む。ルールの正本は `docs/design-principles/`（スキルの `references/` はそこへのシンボリックリンク）。

## 改善が必要な場合

- ルールにギャップがある（判断基準が書かれていない）
- ルールが曖昧で解釈に迷う
- ルールが特定の状況に適合しない
- 同じ例外を繰り返し認める必要がある

## 提案の手順

1. 問題を具体的に説明する
2. `docs/design-principles/` のどのファイルの、どの箇所を、どう変更するか提案する
3. ユーザーの承認を得てから、PR を通じて変更する

**プロダクト固有の例外**: 共有ルールではなく、そのプロダクトの DESIGN.md に記録する。
