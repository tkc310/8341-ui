# ウェブで文章を読むときの F 字型パターン（要約）

- 原文: [F-Shaped Pattern of Reading on the Web: Misunderstood, But Still Relevant (Even on Mobile)](https://www.nngroup.com/articles/f-shaped-pattern-reading-web-content/)（Kara Pernice、Nielsen Norman Group。2017 年公開）
- 確認日: 2026-10-19
- 使っている箇所: [principles.md](../principles.md)「視線のパターン」

## F 字型パターンとは

文章を流し読みするとき、視線は上部を横に走り、少し下がって短く横に走り、そのあと左端を縦に下りる。注視の分布が F の字に見えるため、こう呼ぶ。各行の先頭の数語と、最初の数行がいちばん読まれる。下のほうで興味を引く段落があると E の字に近くなる。対象は本文の領域で、ナビゲーションには当てはまらない。

## 起きる条件

- 見出しや箇条書きのない、ひと続きの文章である
- 早く済ませたい
- すべてを読むほどの動機がない

手がかりがないと、人は左上から始まるいちばん楽な道をたどる。読む語を減らそうとし、求める情報がありそうだと感じられないと読むのをやめる。画面の幅で改行位置が変わるため、目に入る語は端末ごとに変わる。

## ほかの流し読みのパターン

| パターン | 内容 |
| --- | --- |
| レイヤーケーキ | 見出しだけを拾い、本文を飛ばす |
| スポット | リンクや数字など特定のものを探して、大きく飛ばす |
| マーキング | 視線を一点に置いたまま画面を送る（モバイルで多い） |
| バイパス | 箇条書きの各項目で、同じ書き出しの語を飛ばす |
| コミットメント | ほぼすべてを読む（まれ） |

## 影響

右側や下のほうにある大事な情報を見落とし、本人は見落としたことに気づかない。

## 設計の推奨

- いちばん大事なことを最初の 2 段落に書く
- 見出しは見た目ではっきり区別し、情報量の多い語から始める
- 関連する短いまとまりを見た目でグループにする
- 重要な語だけを控えめに太字にする
- 「こちら」ではなく、行き先がわかるリンクの文言にする
- 列挙と手順には箇条書きと番号付きリストを使う
- 不要な文章を削る
