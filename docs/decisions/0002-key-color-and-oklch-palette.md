# 0002 キーカラー「藍」と OKLCH による共通明度カーブ

- 日付: 2026-10-18
- 状態: 採用

## 背景

DADS は青（#0017C1 系）を基調とする。自分用のシステムとして独自の色を持ちつつ、DADS と同等のコントラスト品質を保ちたい。

## 決定

- キーカラーは藍（OKLCH hue 265）。候補は藍 / 青磁（195）/ 藤（300）の 3 案で、青磁と藤は補助色として残した
- 全色相の 13 段階（50〜1200）を、共通の明度カーブ・彩度カーブから生成する（`tokens/palette.config.json`）
- 中立色（墨）は藍の色相にわずかに寄せる（彩度 6%）

## 理由

- 明度カーブが共通なので、段階番号がそのままコントラストの目安になり、色相を変えても semantic の割り当てがほぼ崩れない
- 生成パラメータを JSON で持つため、キーカラーの変更が 1 行で済み、`check:contrast` で即座に検証できる

## 影響・トレードオフ

- 黄色は同じ明度だと濁るため `lightnessShift` で補正している
- sRGB の色域外になる段階は彩度を自動で下げるため、高彩度の色が欲しい場合は別途 primitive を足す
