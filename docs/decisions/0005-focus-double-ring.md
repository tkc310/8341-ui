# 0005 フォーカスの二重リング

- 日付: 2026-10-18
- 状態: 採用

## 背景

WCAG 2.2 の 2.4.13（フォーカスの外観）を満たすには、フォーカス表示が周囲と 3:1 以上の差を持つ必要がある。
DADS は「4px 黒アウトライン + 黄色リング」。ダークテーマでは黒が背景に溶ける。

## 決定

- 内側: `color.focus.ring`（黄 300）を `box-shadow` で 4px
- 外側: `color.focus.outline`（ライトは墨 1200、ダークは墨 50）を `outline` 2px、offset 2px
- リンクは DADS と同様に背景全体も黄色にする
- 強制カラーモードでは `Highlight` のアウトラインのみ

## 理由

明るい背景では外側の濃い線が、暗い背景や暗いボタン上では黄色が、必ず 3:1 以上になる。
`check:contrast` の focus-indicator 規則で、外側アウトラインと全背景の組み合わせを検証している。
