# 0001 React + プレーン CSS

- 日付: 2026-10-18
- 状態: 採用

## 背景
主な利用先は React + TypeScript のプロジェクト。一方で、スタイルは将来 React 以外（静的 HTML、別フレームワーク）にも持ち出したい。

## 決定
- コンポーネントは React + TypeScript で実装する
- スタイルは CSS-in-JS や Tailwind を使わず、CSS 変数（トークン）+ BEM（`tkc-` 接頭辞）+ `data-*` 属性で書く
- CSS は `:where()` などで詳細度を低く保ち、利用側のリセット CSS と共存させる

## 理由
- クラスと data 属性の規約さえ守れば、React 以外でも同じ CSS をそのまま使える（DADS の HTML 版と同じ考え方）
- ランタイムのコストがなく、Server Components とも衝突しない
- data 属性で状態を表すと、セレクタと ARIA 状態の対応が読みやすい

## 影響・トレードオフ
- CSS の未使用部分を自動で削れない（部品数が少ないうちは問題にならない）
- クラス名の衝突は接頭辞の規約で防ぐ
