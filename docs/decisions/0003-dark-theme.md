# 0003 semantic 層でのダークテーマ

- 日付: 2026-10-18
- 状態: 採用

## 背景

DADS はライトテーマのみ。自分用のプロダクトでは OS のダークモードに追従したい。

## 決定

- primitive は共通、semantic カラーだけを `color.light.json` / `color.dark.json` に分けて定義する
- 適用順: `data-theme="dark"` 明示 > `data-theme="light"` 明示 > OS 設定（`prefers-color-scheme`）
- ダークでは面を明るくするほど手前に見せ、影には頼らない。キー背景は明るい藍（300）に暗い文字を乗せる

## 理由

- コンポーネントは semantic しか参照しないため、テーマ追加でコンポーネントを変更せずに済む
- 両テーマでキーが一致しないとビルドが失敗し、コントラストも両テーマで検証される

## 影響・トレードオフ

- 新しい semantic カラーを足すたびに 2 ファイル＋コントラスト規則の更新が必要（意図的な手間）
