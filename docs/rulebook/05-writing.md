# 05 文言

UI の文言はデザインの一部です。見た目と同じく、一貫させます。
design-principles の原則「文言」「誤りと撤回」「一貫性」の必須を満たしたうえで、表記の細則をここで定めます。

## 基本

- です・ます調。ただしボタン・ラベル・見出しは体言止めか動詞の終止形
- 専門用語・略語・カタカナ語は避け、使うなら初出で説明する
- 数字は半角。単位との間はアキなし（`10日`、`5件`）。ただし日付は `2026年10月18日`
- 全角括弧「」（）を使う。英数字だけの補足には半角括弧も可

## ボタン

- 「〜する」の動詞で、押した結果が分かるように書く。「OK」「はい」は避ける
  - ✅ 申請する / 下書きを保存する / 削除する
  - ❌ OK / 実行 / 次へ（何が起きるか分からない場合）
- 破壊的な操作は対象を書く: 「このファイルを削除する」
- 同じ機能には全画面で同じ語を使う。和語の言い換え（直す・消す・やめる・加える）を画面ごとに混ぜない

| 機能 | 一覧の行に並べるボタン | 確定するボタン |
| --- | --- | --- |
| 作る | 「新しい○○を作る」（一覧の見出しの横） | 「保存する」 |
| 直す | 「編集」 | 「保存する」 |
| 消す | 「削除」 | 「削除する」（AlertDialog か、行の中の確認） |
| やめる | — | 「キャンセル」 |
| 一覧から外す（項目そのものは消えない） | 「外す」 | — |

- 一覧の行に同じボタンが並ぶときは、見える文字は短くし、読み上げの名前に対象を入れる（`aria-label="週次レポートを編集"`）

## 確認と完了の知らせ

| 場面 | 書き方 | 例 |
| --- | --- | --- |
| 取り消せない操作の確認（見出し） | 「『対象』を〜しますか」 | 「週次レポート」を削除しますか |
| 確認の説明 | 結果だけを書く | 元に戻せません。 |
| 完了の知らせ（NotificationBanner の success、`live`） | 「『対象』を〜しました。」 | 「週次レポート」を保存しました。 |
| 空の一覧 | 無いことと、次にすること | まだレポートがありません。「新しいレポートを作る」から作成してください。 |

保存と更新で語を分ける（新しく作ったら「保存しました」、直したら「更新しました」）。時間で消える通知にせず、閉じるボタンで消す（design-principles の「状態と応答」）。

## リンク

- 行き先が分かる文にする。「こちら」「詳細」だけにしない
  - ✅ 個人情報の取り扱いを読む
  - ❌ 詳しくはこちら

## フォーム

| 要素                | 書き方                                       | 例                            |
| ------------------- | -------------------------------------------- | ----------------------------- |
| ラベル              | 名詞で短く                                   | 氏名、メールアドレス          |
| 補足（supportText） | 入力形式・例・制約。ラベルの言い換えは書かない（無ければ付けない） | 半角数字 7 桁（ハイフンなし） |
| プレースホルダー    | 入力例のみ。ラベルや説明の代わりにしない     | 例: 1000001                   |
| 必須                | 「必須」バッジ。任意が少数なら「任意」を表示 | —                             |

## エラーメッセージ

**何が起きたか** と **どうすれば直るか** を、利用者を責めない言い方で書きます。

| ❌ 避ける                     | ✅ 書き換え                                                                          |
| ----------------------------- | ------------------------------------------------------------------------------------ |
| 不正な入力です                | メールアドレスに「@」が含まれていません。例: taro@example.jp                         |
| 必須項目です                  | 氏名を入力してください                                                               |
| エラーが発生しました（E1023） | 通信がタイムアウトしました。時間をおいてもう一度送信してください（エラー番号 E1023） |

送信時に複数のエラーがある場合は、ページ上部に NotificationBanner（danger）で件数と各項目へのリンクを並べ、
最初のエラー項目にフォーカスを移します。

## 通知

| 種別    | 使うとき                 | タイトルの例                   |
| ------- | ------------------------ | ------------------------------ |
| info    | 知っておいてほしい情報   | システムメンテナンスのお知らせ |
| success | 操作が完了した           | 申請を受け付けました           |
| warning | このままだと問題が起きる | 提出期限が近づいています       |
| danger  | 問題が起きた・操作が必要 | 2 件の入力内容に誤りがあります |
