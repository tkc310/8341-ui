# 05 文言

UI の文言はデザインの一部です。見た目と同じく、一貫させます。
上流の原則「文言」「誤りと撤回」「一貫性」の必須を満たしたうえで、表記の細則をここで定めます。

## 基本

- です・ます調。ただしボタン・ラベル・見出しは体言止めか動詞の終止形
- 専門用語・略語・カタカナ語は避け、使うなら初出で説明する
- 数字は半角。単位との間はアキなし（`10日`、`5件`）。ただし日付は `2026年10月18日`
- 全角括弧「」（）を使う。英数字だけの補足には半角括弧も可

## ボタン

- 「〜する」の動詞で、押した結果が分かるように書く。「OK」「はい」は避ける
  - ✅ 申請する / 下書きを保存する / 削除する
  - ❌ OK / 実行 / 次へ（何が起きるか分からない場合）
- 破壊的な操作は対象を書く: 「このファイルを削除する」

## リンク

- 行き先が分かる文にする。「こちら」「詳細」だけにしない
  - ✅ 個人情報の取り扱いを読む
  - ❌ 詳しくはこちら

## フォーム

| 要素 | 書き方 | 例 |
| --- | --- | --- |
| ラベル | 名詞で短く | 氏名、メールアドレス |
| 補足（supportText） | 入力形式・例・制約 | 半角数字 7 桁（ハイフンなし） |
| プレースホルダー | 入力例のみ。ラベルや説明の代わりにしない | 例: 1000001 |
| 必須 | 「必須」バッジ。任意が少数なら「任意」を表示 | — |

## エラーメッセージ

**何が起きたか** と **どうすれば直るか** を、利用者を責めない言い方で書きます。

| ❌ 避ける | ✅ 書き換え |
| --- | --- |
| 不正な入力です | メールアドレスに「@」が含まれていません。例: taro@example.jp |
| 必須項目です | 氏名を入力してください |
| エラーが発生しました（E1023） | 通信がタイムアウトしました。時間をおいてもう一度送信してください（エラー番号 E1023） |

送信時に複数のエラーがある場合は、ページ上部に NotificationBanner（danger）で件数と各項目へのリンクを並べ、
最初のエラー項目にフォーカスを移します。

## 通知

| 種別 | 使うとき | タイトルの例 |
| --- | --- | --- |
| info | 知っておいてほしい情報 | システムメンテナンスのお知らせ |
| success | 操作が完了した | 申請を受け付けました |
| warning | このままだと問題が起きる | 提出期限が近づいています |
| danger | 問題が起きた・操作が必要 | 2 件の入力内容に誤りがあります |
