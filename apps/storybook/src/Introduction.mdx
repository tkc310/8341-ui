プロジェクトをまたいで使い回す、自分用のデザインシステムです。
[デジタル庁デザインシステム（DADS）](https://design.digital.go.jp/dads/) のアクセシビリティ基準を土台に、
キーカラー「藍」・ダークテーマを加えて再設計しています。画面設計のルールは
[design-principles](https://github.com/tkc310/8341-ui/tree/main/docs/design-principles) を採用しています。

## 構成

| 層             | 置き場所                    | 技術                                                                                  |
| -------------- | --------------------------- | ------------------------------------------------------------------------------------- |
| トークン       | `packages/tokens`           | W3C DTCG 2025.10 → Style Dictionary v5 → CSS 変数・Tailwind `@theme`・Figma Variables |
| コンポーネント | `packages/ui`               | Base UI v1 + Tailwind CSS v4 + tailwind-variants v3                                   |
| 配布           | `packages/ui/registry.json` | shadcn 方式（コードを持つ）。npm パッケージとしても使える                             |

## 使い方 1: shadcn 方式（推奨）

利用側の `components.json` にレジストリを登録して、コードを取り込みます。

```json
{
  "registries": { "@8341": "https://tkc310.github.io/8341-ui/r/{name}.json" }
}
```

```bash
npx shadcn@latest add @8341/8341-base @8341/button @8341/form-field @8341/text-field
```

`globals.css` で Tailwind の後にテーマを読み込みます。

```css
@import 'tailwindcss';
@import './styles/8341-ui.css';
```

テーマ（`styles/8341-ui.css`）はトークンの CSS を同梱しているので、npm のパッケージは要りません。
トークンを更新したら `npx shadcn@latest add @8341/theme --overwrite` で取り込み直します。
トークンをデータ（`tokens.json` や Figma 用 JSON）として使いたい場合は、このリポジトリの `packages/tokens/dist/` から取得します（npm には公開していません）。

## 使い方 2: npm パッケージ（公開した場合）

npm への公開は既定で無効です。公開すると、次のように使えます。

```tsx
import { Button } from '8341-ui/button';
import '8341-ui/styles.css'; // Tailwind を使わない場合（ビルド済み）
```

Tailwind を使うプロジェクトでは `styles.css` の代わりに次を書きます。

```css
@import 'tailwindcss';
@import '8341-ui/theme.css';
@source "../node_modules/8341-ui/dist";
```

`@source` のパスは、この CSS ファイルから見た `node_modules/8341-ui/dist` への相対パスにします（例: `src/app.css` なら `../node_modules/...`）。
shadcn 方式で部品をコピーした場合は、部品がプロジェクト内にあるので `@source` は不要です。

## テーマ

`<html class="dark">` か `<html data-theme="dark">` でダークにします。どちらも無ければ OS の設定に従います。
ツールバーの Theme で、ライト・ダーク・並べて表示を切り替えられます。
