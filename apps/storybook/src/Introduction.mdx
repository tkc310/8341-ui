# tkc310-ui

プロジェクトをまたいで使い回す、自分用のデザインシステムです。
[デジタル庁デザインシステム（DADS）](https://design.digital.go.jp/dads/) のアクセシビリティ基準を土台に、
キーカラー「藍」・ダークテーマを加えて再設計しています。画面設計のルールは
[design-principles](https://github.com/tkc310/agents-playground/tree/main/docs/design-principles) を採用しています。

## 構成

| 層             | 置き場所                    | 技術                                                                                  |
| -------------- | --------------------------- | ------------------------------------------------------------------------------------- |
| トークン       | `packages/tokens`           | W3C DTCG 2025.10 → Style Dictionary v5 → CSS 変数・Tailwind `@theme`・Figma Variables |
| コンポーネント | `packages/ui`               | Base UI v1 + Tailwind CSS v4 + tailwind-variants v3                                   |
| 配布           | `packages/ui/registry.json` | shadcn 方式（コードを持つ）。npm パッケージとしても使える                             |

## 使い方 1: shadcn 方式（推奨）

利用側の `components.json` にレジストリを登録して、コードを取り込みます。

```json
{
  "registries": { "@tkc": "https://tkc310.github.io/design-system-myself/r/{name}.json" }
}
```

```bash
npx shadcn@latest add @tkc/tkc-base @tkc/button @tkc/form-field @tkc/text-field
```

`globals.css` で Tailwind の後にテーマを読み込みます。

```css
@import 'tailwindcss';
@import './styles/tkc310-ui.css';
```

## 使い方 2: npm パッケージ

```tsx
import { Button } from 'tkc310-ui/button';
import 'tkc310-ui/styles.css'; // Tailwind を使わない場合（ビルド済み）
```

Tailwind を使うプロジェクトでは `styles.css` の代わりに次を書きます。

```css
@import 'tailwindcss';
@import 'tkc310-ui/theme.css';
@source "../node_modules/tkc310-ui/dist";
```

`@source` のパスは、この CSS ファイルから見た `node_modules/tkc310-ui/dist` への相対パスにします（例: `src/app.css` なら `../node_modules/...`）。
shadcn 方式で部品をコピーした場合は、部品がプロジェクト内にあるので `@source` は不要です。

## テーマ

`<html class="dark">` か `<html data-theme="dark">` でダークにします。どちらも無ければ OS の設定に従います。
ツールバーの Theme で、ライト・ダーク・並べて表示を切り替えられます。
